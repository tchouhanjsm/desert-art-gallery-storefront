# Prototype review templates

This folder contains owner decision and review records for the future M2 non-production prototype stage. M2 has not started.

- `m2-owner-entry-decision.md` captures M2-A through M2-E. It records the owner's mixed-image direction, mobile-across-all-journeys rule and shared six-page shell scope, while leaving unresolved choices and gate outcomes open.
- `prototype-review.csv` is a header-only evidence log.
- Use one CSV row per route/scenario/viewport review.
- Record the viewport dimensions, date, outcome and screenshot/evidence reference.
- Keep participant identifiers, contact details, recordings, populated catalogue data and raw research notes out of this repository. Follow `docs/22-CUSTOMER-VALIDATION-PLAYBOOK.md`.
- Run `python3 scripts/audit_m2_readiness.py` to check that owner-input, acceptance and worksheet gate states agree.
- The expanded [M2-A visual study](../../design/explorations/m2-visual-study.html) shows all four territories across homepage, Shop/collection and product detail at desktop/mobile sizes. None is selected or recommended.
- `docs/23-M2-PROTOTYPE-ENTRY-AND-ACCEPTANCE.md` defines the six-route shell, segment hypotheses, mixed-image evidence rules and cross-journey responsive acceptance.
- The presence of these templates does not mean M2 has started or that any visual direction is approved.
