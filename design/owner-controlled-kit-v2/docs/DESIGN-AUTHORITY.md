# Design Authority — Kit-local Reference

**Repository-root `docs/DESIGN-AUTHORITY.md` is authoritative.** This file is retained with the kit as a local summary and must not override the project root.

## Governing rule

D-014 adopts this kit as the sole active structural HTML/CSS source for nine pages. Preserve supplied original HTML, CSS, responsive styles, structural components, page order and component inventory. Do not redesign, restyle, expand or reinterpret the kit.

## Owner-controlled identity

The owner alone approves exact colours, typography families/weights/hierarchy/type scale, logo/wordmark/descriptor, photography direction/crops and factual customer-facing claims. These values remain pending. The layout-only token fallback is QA only, not a DAG palette or production theme.

## No-additions rule

Do not add unlisted pages, sections, shell items, navigation, components, banners, promotions, testimonials, reviews, badges, widgets, icons, animations, chat, newsletter/social modules, popups, sticky/floating features or interactions. Existing disabled/visual-only controls remain disabled.

## Content and language

Customer-facing content is English-only. Never fabricate products, makers, material, dimensions, prices, stock, provenance, reviews, contact details, policies or delivery promises. Use only verified owner-approved content and assets.

## Reference/IP boundary

POJ Studio is the primary ecommerce/page-structure reference; Macaroni Shoten is secondary for curation/select-retail character. Study non-proprietary principles only. Do not copy their source code, CSS, layouts, assets, logos, fonts, copy or photography.

## Authorization

D-014 is structural adoption only. It does not authorize production application development, final branded styling, framework/backend selection, commerce behaviour or public deployment. Any change requires written proposal, explicit owner approval in the root decision register and inventory amendment.
