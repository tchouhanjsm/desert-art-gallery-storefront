## Shared shell

Preserve the supplied kit-only notice, utility location row, text wordmark/descriptor placeholder, navigation (Shop, Collections, About, Makers, Journal, Contact), mobile navigation toggle, disabled Search action where present, Enquire action where supplied and footer groups.

## Exclusions

No cart, checkout, account, wishlist, payment, orders, live search/filter/sort, functional variants, shipping calculation, returns workflow or enquiry backend. Do not add, remove, rename or reorder pages, sections or navigation without explicit owner approval and an inventory amendment.
