# Kit Documentation Source of Truth — v2

The repository-root `docs/DOCUMENTATION-SOURCE-OF-TRUTH.md` is the governing policy. This kit-local copy is a scoped summary.

## Current baseline

D-014 adopts the DAG Owner-Controlled Design Kit v2 as the sole active structural HTML/CSS baseline. It contains exactly nine HTML pages, four CSS files and the supplied `scripts/prototype.js`. Preserve the supplied page/section order, component structure, responsive rules, placeholders and disabled states.

## What it does not approve

- Final brand colours or palette.
- Typography families, weights, hierarchy or scale.
- Logo, wordmark or descriptor.
- Photography art direction/cropping.
- Final customer-facing claims or product data.
- Production application framework or backend.
- Cart, checkout, payments, accounts, live search/filter/sort or other excluded commerce functionality.

`styles/tokens-layout-only.css` uses system canvas colours and system fonts for structural QA only. It is not a DAG palette or production theme.
