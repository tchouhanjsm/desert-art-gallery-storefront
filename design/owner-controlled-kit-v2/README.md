# DAG Owner-Controlled Design Kit v2

This directory contains the owner-supplied, framework-independent HTML/CSS structural kit adopted by decision D-014.

## Status and authority

**Structural scope: owner-approved. Brand identity: not approved. Production application: not authorized.**

The project-root authority remains controlling: read repository-root `AGENTS.md`, `docs/DECISIONS.md`, `docs/DESIGN-AUTHORITY.md`, `docs/DOCUMENTATION-SOURCE-OF-TRUTH.md`, and the active page/component inventories. These kit-local documents are subordinate and must not override the repository-root hierarchy.

The original 14 HTML/CSS/JS source assets are preserved. The four `styles/` files include `tokens-layout-only.css`, which uses browser system canvas colours and system fonts for layout QA only. It is not a DAG palette or production theme. Exact brand colours, typography, wordmark/descriptor and photography direction remain owner-controlled and pending.

Open `index.html` directly in a browser and navigate to the nine pages under `pages/`. This is a non-production structural preview, not a live store.

## Deliberate exclusions

Cart, checkout, account, wishlist, live search/filter/sort, payment, order operations, shipping calculation, returns workflow and enquiry backend are not included. Existing disabled controls stay disabled. No page, section, component, UI or functionality may be added without explicit owner approval and an inventory amendment.

## Language, content and photography

Customer-facing content remains English-only. Japan-first does not imply Japanese-language UI or settle seller jurisdiction, sales territory or commerce policy. All product, maker, material, dimension, provenance, price, stock, review and business information must be verified. Keep supplied placeholders until approved facts and assets exist. Genuine product photographs require verified mapping, rights and publication approval; use labelled placeholders for gaps.
